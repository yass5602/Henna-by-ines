La connexion à la base de données gratuite (Supabase) n'est pas encore renseignée dans config.js.
  1. Créer un projet gratuit sur supabase.com.
  2. Exécuter le fichier supabase-setup.sql (SQL Editor).
  3. Créer le compte administrateur (Authentication > Users).
  4. Copier l'URL et la clé publique dans config.js, rubrique supabase.

Le détail pas à pas se trouve dans ADMIN-SETUP.md.
